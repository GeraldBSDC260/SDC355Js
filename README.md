# Portfolio Page

## Overview
This portfolio page dynamically renders project data using JavaScript objects, arrays, DOM manipulation, and session storage.

The page demonstrates how structured data can be stored, retrieved, and programmatically rendered to create reusable UI components.

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
- Browser Session Storage API
- DOM Manipulation

## Features
- Project data stored as JavaScript objects
- Objects stored in an array
- Data serialized using JSON.stringify()
- Data stored in sessionStorage
- Data parsed using JSON.parse()
- Projects dynamically generated on page load

## Dependencies
No external dependencies required.
This project runs in any modern browser.

## How to Run
1. Clone the repository.
2. Open `index.html` in your browser.
3. Projects will render automatically.
